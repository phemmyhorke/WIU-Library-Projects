Integration Notes for wiu.edu/libraries

  • Embed this as a standalone page or inside current CMS content using an <iframe>.
  • Connect to a backend endpoint: POST /api/appointments that creates Google Calendar events using service account delegation.
  • Use Google Calendar API for free/busy lookup to avoid double booking across faculty calendars.
  • Send confirmation email + .ics invite to both requester and faculty member.
  • Add SSO guard if needed (CAS or Microsoft Entra), but allow guest booking for community patrons if policy permits.
